## 工作模式

![状态机流程图](images/state-machine.png)
*系统状态机 — 三种模式切换与 AUTO 子状态*

### 模式 0 — 关灯

```
按键切入 → MOSFET_Update(0) → 灯灭
```

LED 强制熄灭，编码器旋钮和所有传感器均被忽略。适合夜间休息或不需要照明时使用。

### 模式 1 — 手动调光

```
按键切入 → 读取编码器值 count (0~19) → MOSFET_Update(count) → 灯按设定亮度常亮
```

旋转编码器直接控制 LED 亮度。顺时针增亮，逆时针减暗。亮度上限锁定在 PWM 20%，防止过流。

![手动调光](images/demo-manual.jpg)
*旋钮调光演示*

### 模式 2 — 全自动

![AUTO 子状态](images/demo-auto-sequence.jpg)
*AUTO 模式完整流程：人来 → 灯亮 → 活动保持 → 无人关灯*

**核心规则：**

| 条件 | 动作 |
|:----|:----|
| PIR 检测到人 | **开灯**，LDR 设定初始亮度 |
| 声音检测到活动 | 刷新 5 秒超时定时器，保持灯亮 |
| 5 秒内无活动 | **自动关灯** |
| 旋钮被转动 | 立即切至手动模式（用户接管） |
| 灯亮期间 | LDR 持续采样，带 50 级滞回升降亮度 |

**自动调光逻辑：**

```
环境暗 → ADC 值大 → 映射 PWM 值大 → 灯更亮
环境亮 → ADC 值小 → 映射 PWM 值小 → 灯更暗
```

## 核心参数

| 参数 | 值 | 说明 |
|:----|:---:|:----|
| PWM 频率 | 10 kHz | TIM2, PSC=71, ARR=99 |
| 亮度上限 | 20% | 限流保护，PWM 最大值 19 |
| 编码器步数 | 20 步/圈 | 一圈从暗到最亮 |
| 控制周期 | 50 ms | 主循环 HAL_Delay(50) |
| 自动关灯超时 | 5 s | 无活动自动熄灭 |
| 声音去抖 | 2 次采样 (100 ms) | 滤除噪声尖峰 |
| LDR 滞回 | 50 ADC 值 | 防止亮度频繁跳变 |
| LDR 采样 | 10 次平均 | 平滑采样值 |
| ADC 分辨率 | 12-bit (0~4095) | 映射到 PWM 0~19 |
| 供电电压 | 12V / 5V / 3.3V | 灯条 / 模块 / MCU |

## 模块详解

### STM32F103C8T6 主控

![主控模块](images/modules/stm32.jpg)
*STM32最小系统板 — 72MHz Cortex-M3，64KB Flash*

负责传感器采集、模式状态机运行、PWM 输出控制。

### KY-040 旋转编码器

![编码器模块](images/modules/ky040.jpg)
*KY-040 旋转编码器 — 20 脉冲/圈，带按键*

双用途设计：
- **旋转** → 手动模式下调亮度 / AUTO 模式下切手动
- **按下** → 循环切换 MODE_OFF → MODE_MANUAL → MODE_AUTO

### HC-SR501 PIR 人体感应传感器

![PIR 模块](images/modules/pir.jpg)
*HC-SR501 人体红外传感器 — 检测范围约 3~7 米*

AUTO 模式下，**仅有 PIR 可以触发开灯**，声音只能维持已有灯光。

### KY-037 声音传感器

![声音模块](images/modules/sound.jpg)
*KY-037 声音传感器 — 带数字输出，灵敏度可调*

软件去抖设计：连续 2 次采样（100ms）确认有效信号，滤除噪声。

### LDR 光敏电阻模块

![光敏模块](images/modules/ldr.jpg)
*LDR 光敏模块 — 模拟电压输出，12-bit ADC 采样*

自动亮度调节依据：环境越暗 → 输出 PWM 越大 → 灯越亮。

### MOSFET PWM 驱动

![MOSFET 模块](images/modules/mosfet.jpg)
*N-MOSFET 驱动板 — PWM 控制 12V LED 灯条*

PWM 占空比上限锁定 20%，确保灯条安全工作。
